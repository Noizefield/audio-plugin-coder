# evals/

Deterministic AI eval harness for APC. See `.agents/guides/evals.md`.

- `tasks/<id>/` - `task.json`, `fixture/` (copied to the agent workspace), `reference/good|bad/` (self-test overlays, never shown to agents)
- `results/ledger.jsonl` - one row per recorded run (append-only)
- `LEADERBOARD.md` - generated by `apc eval leaderboard --out evals/LEADERBOARD.md`

Quick start: `node bin/apc.js eval list` then `node bin/apc.js eval run add-parameter --prepare`.
